## Page 8

Informed Search Strategies
Remember
• A heuristic function h(n) is admissible if it never
overestimates the cost for reaching the goal
• A heuristic function h(n) is consistent (monotone) if, for
each node n for every successor n’ of n applying operator
a, the following holds:
h(n) £ c(n, a, n’) + h(n’)

## Page 26

Some observations
• Optimality in a A* algorithm on graphs
is guaranteed if the heuristic is
consistent.
• For obtaining optimality, we have two
ways:
1. Chose a consistent heuristics
2. Modify the algorithm and updating the cost
to reach a node (the g cost) each time a
node is reached through a better cost path
This update should then be propagated
properly.
